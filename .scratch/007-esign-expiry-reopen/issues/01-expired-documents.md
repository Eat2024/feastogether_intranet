# 01: 文件到期改為已到期，保留人工停止

**What to build:** 文件到期後停止接受新簽署，建立人及簽署人可辨識「已到期」。已簽署證據、個人副本產製與下載仍可用；建立人可以永久停止文件。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 到期持久化為 expired；背景處理延遲時查詢／篩選仍顯示已到期，截止當下不得新增簽署。
- [ ] 狀態 migration 保留既有 stopped 與證據；不新增欄位、資料表或排程。
- [ ] 目前期限與原始期限分開呈現；固定 payload 與 hash 不變。
- [ ] 到期只記一次稽核，未簽邀請失效；到期文件可由建立人永久停止，finalizing 行為維持。
- [ ] 已簽署者的來源讀取、副本產製／下載與簽章驗證不受新狀態影響。
- [ ] 相關單元、schema、HTTP／資料庫驗收及 lint/build 通過；契約與文件反映新行為。

## 交付界線

本張是可由正式後端 API 驗收的完整增量。前端正式串接另行交付。下一張才加入重新開放入口。
