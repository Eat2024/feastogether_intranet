# 02: 建立人重新開放補簽

**What to build:** 建立人為已到期文件填寫新截止時間與原因，原未簽署者可以繼續簽署。可多次補簽，保留完整歷程；外部簽署人使用新邀請，舊連結與舊寄信工作不能影響新資格。

**Blocked by:** 01: 文件到期改為已到期，保留人工停止

**Status:** ready-for-agent

- [ ] 僅建立人可對已到期且仍有未簽者的文件立即補簽；新期限必須在未來，原因 trim 後 1–500 個 Unicode code points。
- [ ] 比對建立人讀取的期限，防止同輪並發及跨輪舊要求重送；交易失敗不留下部分狀態。
- [ ] 原始文件、簽署對象、已簽證據與副本不變；多輪補簽最終仍沿用既有完成流程。
- [ ] 每輪記錄前後期限、原因、操作者與時間；簽署人不能取得內部原因或操作者。
- [ ] 外部未簽者取得新邀請，建立人可以唯讀取得並轉交；不新增自動通知。舊 token／cookie 與通知工作不能恢復或清除新資格。
- [ ] 已停止、已完成及 finalizing 不可補簽；舊到期停止文件不恢復。
- [ ] 單元、HTTP、安全性、真實資料庫競態與既有證據回歸驗證通過，契約及前端交接文件完整。

## 交付界線

邀請輪替與舊通知防護同一張完整交付，不拆成不安全的中間版本。前端正式串接另行交付。
