# 02: 外部簽署人可從邀請信完成簽署

**What to build:** 外部簽署人點開邀請信、按下「開啟電子簽署文件」後，進入外部簽署頁：先閱讀並同意電子簽署聲明，再逐頁閱讀文件、在每個簽名欄位親手簽名，勾選同意後確認送出，看到簽署成功。桌面與手機都能完成。這是第一個可實際走完的 tracer bullet，直接使用後端既有的外部簽署 API。

**Blocked by:** 01: 共用簽署元件與副本讀取的前置重構

**Status:** resolved

- [x] 外部簽署頁不在員工側邊欄版面內，只有深色「電子簽署」頁首；畫面風格依設計稿（同意聲明、閱讀與簽名・桌面、閱讀與簽名・手機）。
- [x] 步驟依序為「同意授權條款 → 閱讀文件 → 完成簽名 → 確認送出」，畫面持續顯示目前步驟。
- [x] 同意聲明顯示後端目前有效的聲明全文與版本；未勾選同意前不能進入閱讀與簽名。
- [x] 可逐頁瀏覽原始文件、看到需簽名的頁面與欄位；日期欄位顯示簽署當天日期且不可編輯。
- [x] 每個簽名欄位以簽名板親手簽名，可重新簽名；未完成所有簽名或未勾選同意時不能送出，並提示缺少的項目。
- [x] 送出前再次確認；送出中按鈕轉圈並避免重複送出；網路錯誤重試時沿用同一次請求的識別，不會重複簽署。
- [x] 沒有「拒絕簽署」；畫面只顯示文件名稱、本人姓名與 Email、簽署期限，不顯示其他簽署人或建立人內部資訊。
- [x] 存取失效時顯示與「邀請連結無效或已到期」相同內容的卡片；其他錯誤以繁體中文訊息提示。
- [x] 手機寬度下，簽名進度、同意勾選與確認簽署固定在畫面底部，簽名板全螢幕開啟。
- [x] 送出成功後顯示簽署成功畫面（下載功能屬 05）。
- [x] client lint、build 通過；以測試庫建立的邀請在桌面與手機寬度（瀏覽器模擬）各完成一次簽署，建立人 API 顯示已簽署。真實邀請信、真機與建立人畫面確認移至 09。
