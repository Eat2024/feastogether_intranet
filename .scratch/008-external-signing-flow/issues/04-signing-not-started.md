# 04: 簽署尚未開始時顯示開始時間

**What to build:** 建立人把簽署開始日設在未來時，邀請信會先寄出。簽署人在開始時間前按下「開啟電子簽署文件」，看到「簽署尚未開始，請於（開始時間，台北時間）後簽署」，而不是失效頁；開始後用同一連結即可正常簽署。

**Blocked by:** 03: 邀請確認頁與失效頁依設計稿改版

**Status:** claimed

- [ ] 只有在邀請憑證有效、簽署人待簽署、文件簽署中且尚未到開始時間時，才顯示「簽署尚未開始」頁（設計稿 ① 尚未開始），以台北時間顯示開始時間。
- [ ] 尚未開始時不設存取 cookie、不記錄開啟、不顯示任何文件內容。
- [ ] 無效、竄改或其他期間外的情況仍顯示通用失效頁，不揭露開始時間。
- [ ] 新增的「尚未開始」錯誤有穩定錯誤碼與繁體中文訊息，其他外部 API 遇到相同情況回相同錯誤。
- [ ] 單元測試涵蓋開始前、開始當下、期間內與期間外；e2e 以未來開始日驗證 409 頁面、開始時間、沒有 Set-Cookie、沒有開啟稽核，並在開始後可正常建立存取。

## 交付界線

與 05 都會調整外部存取的授權判斷，兩票同時進行時須留意同一處程式的衝突。
