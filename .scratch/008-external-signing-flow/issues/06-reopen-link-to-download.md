# 06: 已簽者日後重新開啟連結下載

**What to build:** 外部簽署人簽完並關閉瀏覽器後，日後任何時間（包含簽署期限過後、文件被停止或已完成）再次點開邀請信中的連結、按下開啟，都直接進入簽署完成頁並可下載本人副本，不會再出現簽署步驟。

**Blocked by:** 05: 簽完立即下載本人副本

**Status:** claimed

- [ ] 已簽者重新開啟邀請時重新取得存取（session cookie），導向外部簽署頁並直接顯示完成頁；待簽者仍依簽署期限取得帶期限的存取。
- [ ] 已簽者的開啟與下載不設期限，不受原簽署期限、補簽、文件停止或完成影響；只有文件或簽署人被刪除時失效。
- [ ] 待簽者在文件停止、到期或簽署期限過後開啟，仍顯示失效頁。
- [ ] 單元測試涵蓋已簽者在文件各狀態下建立存取；e2e 驗證：沒有 cookie 的新請求重新開啟後可下載、簽署後文件被停止仍可下載而同文件待簽者被拒、時間推進到簽署期限之後已簽者仍可下載而待簽者被拒；改寫既有停止競態的斷言（競態中簽署成功時，之後重新開啟應成功）。
- [ ] 以另一個瀏覽器重新開啟原邀請連結，人工確認直接進入完成頁並可下載。
