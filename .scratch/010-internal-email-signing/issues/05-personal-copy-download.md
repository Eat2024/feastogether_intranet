# 05: 簽署後透過 OTP 取得個人副本

**What to build:** 已簽署員工可在同次驗證或日後重開原邀請並重新 OTP 後，取得本人簽署副本；停止、到期或完成不剝奪下載權利，刪除後不可存取。

**Blocked by:** 04 內部員工透過 Email＋OTP 簽署或拒簽。

**Status:** ready-for-agent

**Spec:** 010 — US3、FR-010、FR-012～013、FR-017。對應 T029～T032。

**執行約定:** 前置 resolved 才開始；沿用既有 PDF worker、產物、浮水印與證據，不新增副本種類或期限。不修改 client、不部署；驗收並整合後才 resolved，追加驗證與 commit 紀錄。

- [ ] 本人結果正確回報 pending／processing／ready／failed；未就緒下載回 409，未簽及已拒簽者不能下載簽署副本。
- [ ] 簽署成功不清除現有有效 cookie；有效存取可下載本人副本，8 小時失效或新瀏覽器須重新 OTP，不可用一般員工 session 取代。
- [ ] 已簽者原邀請在停止、到期、完成後仍可重新驗證下載，不設下載期限；仍驗證邀請世代、文件關聯與 credential，刪除後拒絕，不能重簽。
- [ ] 沿用產物完整性檢查，損壞產物不提供；本人與建立人取得同一副本的 PDF bytes 一致，歷史證據 hash 不變。
- [ ] 跨人、跨文件及錯誤 cookie 無法讀取原檔、結果或副本；讀取保持 GET 唯讀與 private,no-store。
- [ ] 隔離環境由測試 worker 產生真實測試產物，完成 HTTP 下載、重新 OTP 下載及狀態／授權測試，記錄結果；前端輪詢與手機畫面驗收仍列未實作。
