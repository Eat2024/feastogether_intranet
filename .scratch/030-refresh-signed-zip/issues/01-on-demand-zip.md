**What to build:** 員工可看到目前 ZIP 與未納入的新簽署份數，需要時才按更新取得包含全部已簽副本的新版；沒有新增則沿用現有成果。這是完整的讀取、申請、畫面與內容驗證切片。

**Blocked by:** None (can start immediately)

**對應 Tasks:** T001–T013

**Status:** claimed

- [ ] 無人簽署不產生空 ZIP；已有簽署則可首次產製。
- [ ] 1 人舊 ZIP 加第 2 人後只讀顯示過時，明確更新才產出實際包含 2 份正確 PDF 的 ZIP。
- [ ] 新增 100 筆簽署及純讀取不自動建工作；無變更下載 10 次不新增工作或歷史。
- [ ] 後端依簽署紀錄身分判斷新增，不相信畫面人數；同數不同紀錄可辨識，僅改名或副本就緒不重包。
- [ ] 畫面分開目前可下載成果與更新工作；更新中舊版清楚標示份數且仍可下載。
- [ ] 現有多版取最新曾成功版，缺檔不退回更舊版；有新增仍可明確要求新版。
- [ ] 沿用文件權限、不揭露快照、不新增 schema；service、內容及瀏覽器驗證結果可查。

**交付界線:** 隔離環境可示範，不單獨上版；安全並行與舊版停用清理仍由後續 tickets 完成。
