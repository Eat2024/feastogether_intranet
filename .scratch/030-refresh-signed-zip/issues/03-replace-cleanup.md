# 03: 新版成功後取代與清除舊 ZIP

**What to build:** 新版確認可用後停用舊 ZIP 並清除實體檔，歷史保留且標示已取代；刪除失敗或中斷能補清理而不影響新版與個人 PDF。

**Blocked by:** 02：固定下載範圍與並行更新共用

**對應 Tasks:** T020–T028

**Status:** ready-for-agent

- [ ] 新版成功前舊版可下；發布失敗不能先停用或刪除舊成果。
- [ ] 成功切換後舊連結、準備下載及續傳請求拒絕舊版，不冒充提供新版。
- [ ] 舊版歷史保留原匯出人、時間、份數與名稱，標示已取代且無下載／重試。
- [ ] 清理只刪同文件被取代 ZIP，不刪其他文件、目前有效版、原始文件、簽署證據或個人 PDF。
- [ ] 刪檔失敗維持待清理且新版可下載；切換後中斷、刪成功但回寫前中斷、重複清理均可恢復。
- [ ] 補清理有界且失敗延後，避免失敗首批阻擋其他待清理工作；沿用維護流程，不新增排程。
- [ ] local 與 S3 驗證實體檔／指定版本真正不存在；不可只靠 mock 或 delete marker 宣稱完成。
- [ ] 非同部門、未登入、錯文件與錯檔案引用仍受保護，錯誤不洩漏其他文件資訊。

**交付界線:** 發布、停用下載與補清理是同一個可驗收切片，不能只交付刪檔或只交付畫面。
