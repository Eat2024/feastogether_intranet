## 電子簽列表（/forms）與其下的頁面

| 功能 | 狀況 | 需要誰 |
|---|---|---|
| **補簽** | 按鈕停用；已到期狀態、補簽後的期間顯示、歷程事件都已準備好，只差 API | 後端：補簽 API |
| 檢視頁「拒絕原因」、「已拒絕」分頁 | 標示「未支援」 | 後端：拒簽流程 |
| 檢視頁「通知」、批次通知、「通知紀錄」 | 按鈕停用；通知紀錄只顯示外部簽署人的邀請信狀態 | 後端：催簽 API、通知紀錄 |
| 檢視頁「備註」 | 可輸入，但只暫存在頁面上 | 後端：簽署人備註 API |
| 簽署歷程看不出是哪位簽署人 | 簽署人的動作都顯示「系統」 | 後端：歷程回傳簽署人身分 |
| 匯出「已簽署文件 ZIP」 | 選項停用 | 後端 |
| 匯出的拒絕時間、拒絕原因欄位 | 標示「未支援」，匯出空白 | 後端：拒簽流程 |
| 匯出紀錄（歷史匯出文件頁） | 後端已完成（Spec 015），待前端串接；頁面仍是 mock。後端已移除舊的 PDF 下載 GET 與 ZIP 清單路由，前端必須跟後端一起部署 | 前端：依 `specs/015-export-history/contracts/export-history-http-api.md`「前端交接」 |
| 已發起、還沒人簽時編輯 | 後端只允許改草稿 | 產品決定，要做的話需要後端 |
| 停止時通知待簽署者、封存已停止文件 | 尚未實作 | 後端 |
| 文件編號是 UUID | 列表、標題、匯出檔名都會出現一長串 UUID | 後端決定編號格式 |

## 新增電子簽文件（/forms/new）

| 功能 | 狀況 | 需要誰 |
|---|---|---|
| 暫存簽署期間 | 目前只能暫存名單，期間要在發起時才設定 | 後端：草稿是否要存期間 | 加存期間
| 浮水印、開放拒絕簽署 | 選項停用，固定送 `false` | 後端：浮水印繪製、拒簽 API，並回傳 `allowReject` | 後端畫浮水印 前端刪功能


## 給後端的清單（依影響程度排序）

1. **補簽 API**：唯一「前端已全部準備好、只差 API」的項目。
2. **拒簽流程**：一次解決檢視、匯出、設定簽署三處的「未支援」。
3. **催簽與通知紀錄**，以及**停止時通知待簽署者**。
4. **簽署人備註 API**。
5. **歷程回傳簽署人身分**。
6. **草稿是否儲存簽署期間**。
7. **浮水印繪製**、**已簽署文件 ZIP**、**匯出紀錄**（後端已完成，待前端串接）。
8. **系統簽署確認頁**、**簽到表**。
9. 產品決定：文件編號格式、已發起文件能否編輯、已停止文件要不要封存。

## 前端不用等後端就能做的

- 停止後「複製為新文件」（先不帶簽署名單）
- 上表兩個待實測的項目：第 1 步換 PDF、不在組織架構中的已存簽署人提示
