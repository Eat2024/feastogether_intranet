## 明確的交付界線

- 前端僅 027 的隱藏登入、必要身分顯示／登出及 029 的側邊選單；不製作 OAuth 登入／callback、角色管理、員工指派、其他業務頁面或全頁按鈕改造。
- 沒有 OAuth callback 前端不等同後端流程未保留；本次不能宣稱獨立瀏覽器 OAuth 入口已完整交付。既有 WebView 必須持續可用。
- 後端管理 API 與 REPL 完整交付，即使本次沒有管理畫面；只隱藏選單不足以完成授權。
- 不搬 CKS 驗收業務、SAP、整套 JWT／Redis session 或全域單一角色。
- Super user 共用帳號只可追查維護身分，不宣稱知道實際保管者；不以假員工解決其文件操作與稽核關聯。
