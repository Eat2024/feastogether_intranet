## Content Quality

- [x] 主規格未指定實作語言、框架或套件；API 草案獨立保存，路由與錯誤碼留待 plan 定稿。
- [x] 需求涵蓋草稿、浮水印、批次副本匯出、拒簽、外部催簽、備註與可追溯歷程。

## Requirement Completeness

- [x] 人資可跨建立人匯出所有簽署文件；催簽以台北時間每日午夜重置，已無未處理的澄清標記。
- [x] 需求可測試，區分簽署成功與拒簽流程完成，不把拒簽者納入 PDF 匯出。
- [x] 成功標準具體：資料一致率、6,000 份、4 GiB 以上、受理時間與正常簽署影響。
- [x] 成功標準不依賴特定套件或實作技術；效能數字明確為待驗證目標。
- [x] 六個獨立故事均具正常、失敗及權限驗收情境。
- [x] 涵蓋部分日期、清空、跨時區、並發發起、舊文件、旋轉裁切、缺檔、中斷、同名及無可匯出副本。
- [x] 清楚限定單一文件的 PDF 副本 ZIP，排除跨文件總匯出及其他未確認功能。
- [x] 列出既有權限、個人副本、外部本人下載及既有補簽規格的相依關係；拒簽已併入本規格。

- [x] 催簽本階段僅支援外部；全部通知、指定混合名單、可通知人數與未寄送原因均一致。
- [x] 已記錄內部同事催簽為後續規格，未將此外部限制套用到拒簽與備註。
