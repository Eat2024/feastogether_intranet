## 01: 受理後立即顯示確認日期與預計人數

**What to build:** 發起受理後即回到同一文件的列表列，顯示發起中、本次確認期間與 0/N；背景尚未開始也可確認操作成功。

**Blocked by:** None (can start immediately)

**對應 Tasks:** T001–T008

**核准時初始 Status:** ready-for-agent

- [ ] 1、100、5213 人皆沿用背景發起；不新增文件、不預建正式簽署人。
- [ ] 期間以本次提交為準，與舊草稿不同時仍顯示正確；N 為受理總數而非寄信或處理數。
- [ ] 已受理資料可由列表讀取；未可靠受理不顯示假摘要。
- [ ] 既有正式計數不被預計人數覆寫；不擴充簽署權限或新增 schema。
- [ ] 受理後首次列表及摘要合約測試通過，完成單人及多人瀏覽器示範。

## 02: 重新進入與原有讀者取得一致摘要

**What to build:** 發起人重整、同部門原可讀者重新開啟時看見相同期間與人數，日期篩選一致，且發起中仍禁止異動。

**Blocked by:** 01：受理後立即顯示確認日期與預計人數

**對應 Tasks:** T009–T011

**核准時初始 Status:** ready-for-agent

- [ ] 重整、重新開啟與同部門原可讀帳號可看到相同摘要；不可讀者不能取得資料。
- [ ] 只回傳日期與人數，不回傳完整名單、信箱、憑證或租約。
- [ ] 日期篩選與排序使用畫面顯示的受理期間，台北日期不偏移。
- [ ] 排隊、執行、重試等待均禁止文件／簽署人異動、刪除、重複發起及提前簽署。
- [ ] 權限與保護回歸、窄螢幕及多分頁人工驗收有紀錄。

## 03: 背景終態與快取競態正確切換

**What to build:** 背景成功後自動顯示正式資料；最終失敗恢復草稿；重試保留摘要，快速完成及較晚回應不使畫面倒退。

**Blocked by:** 01：受理後立即顯示確認日期與預計人數

**對應 Tasks:** T012–T014

**核准時初始 Status:** ready-for-agent

- [ ] 正式成功與最終失敗後 5 秒內更新，暫時重試仍顯示同一摘要。
- [ ] 兩連線競態驗證列表回應不混用任務與正式統計，下一輪收斂。
- [ ] 正式狀態快取不會被較晚受理回應覆蓋成發起中。
- [ ] 網路讀取失敗不被誤認為工作失敗或成功；離頁或無進行中任務停止輪詢。
- [ ] 通知白名單略過不改變發起狀態；不新增取消、失敗詳情或重試介面。

**What to build:** 確認 5213 人使用情境快速返回列表、背景安全完成，並備妥可部署與可回滾的完整驗收證據。

**對應 Tasks:** T015–T018
