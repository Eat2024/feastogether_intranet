## 01: 新簽署提醒與按需更新 ZIP

**What to build:** 員工可看到目前 ZIP 與未納入的新簽署份數，需要時才按更新取得包含全部已簽副本的新版；沒有新增則沿用現有成果。這是完整的讀取、申請、畫面與內容驗證切片。

**Blocked by:** None (can start immediately)

**對應 Tasks:** T001–T013

**Status:** 草案，待使用者確認（發布後 ready-for-agent）

- [ ] 無人簽署不產生空 ZIP；已有簽署則可首次產製。
- [ ] 1 人舊 ZIP 加第 2 人後只讀顯示過時，明確更新才產出實際包含 2 份正確 PDF 的 ZIP。
- [ ] 新增 100 筆簽署及純讀取不自動建工作；無變更下載 10 次不新增工作或歷史。
- [ ] 後端依簽署紀錄身分判斷新增，不相信畫面人數；同數不同紀錄可辨識，僅改名或副本就緒不重包。
- [ ] 畫面分開目前可下載成果與更新工作；更新中舊版清楚標示份數且仍可下載。
- [ ] 現有多版取最新曾成功版，缺檔不退回更舊版；有新增仍可明確要求新版。
- [ ] 沿用文件權限、不揭露快照、不新增 schema；service、內容及瀏覽器驗證結果可查。

**交付界線:** 隔離環境可示範，不單獨上版；安全並行與舊版停用清理仍由後續 tickets 完成。

## 02: 固定下載範圍與並行更新共用

**What to build:** 持續簽署期間仍能下載本次固定範圍的成果；多人點擊共用同一工作，失敗重試不改範圍，離開再返回仍可看到進度。

**Blocked by:** 01：新簽署提醒與按需更新 ZIP

**對應 Tasks:** T014–T019

**Status:** 草案，待使用者確認（發布後 ready-for-agent）

- [ ] 以 13 份受理後新增第 14 人，不取消、追加、重啟或自動排下一版；完成仍可下載 13 份並提示缺 1。
- [ ] 10 個並發申請共用同一工作；重複點擊及過時畫面不建立重複工作。
- [ ] 已簽但個人 PDF 尚未就緒者等待，不以缺檔 ZIP 宣告完成。
- [ ] 新版失敗仍可下載舊版；適用重試保留原工作與快照，較舊失敗及完整性錯誤不可繞過。
- [ ] 完成後「下載本次成果」與「再次更新」明確分開，前者不會觸發打包。
- [ ] 離頁重開可恢復同工作；完成、失敗時畫面及歷史快取一致。
- [ ] 並發、工作重送、固定內容及雙 session 驗證通過並留下證據。

## 03: 新版成功後取代與清除舊 ZIP

**What to build:** 新版確認可用後停用舊 ZIP 並清除實體檔，歷史保留且標示已取代；刪除失敗或中斷能補清理而不影響新版與個人 PDF。

**Blocked by:** 02：固定下載範圍與並行更新共用

**對應 Tasks:** T020–T028

**Status:** 草案，待使用者確認（發布後 ready-for-agent）

- [ ] 新版成功前舊版可下；發布失敗不能先停用或刪除舊成果。
- [ ] 成功切換後舊連結、準備下載及續傳請求拒絕舊版，不冒充提供新版。
- [ ] 舊版歷史保留原匯出人、時間、份數與名稱，標示已取代且無下載／重試。
- [ ] 清理只刪同文件被取代 ZIP，不刪其他文件、目前有效版、原始文件、簽署證據或個人 PDF。
- [ ] 刪檔失敗維持待清理且新版可下載；切換後中斷、刪成功但回寫前中斷、重複清理均可恢復。
- [ ] 補清理有界且失敗延後，避免失敗首批阻擋其他待清理工作；沿用維護流程，不新增排程。
- [ ] local 與 S3 驗證實體檔／指定版本真正不存在；不可只靠 mock 或 delete marker 宣稱完成。
- [ ] 非同部門、未登入、錯文件與錯檔案引用仍受保護，錯誤不洩漏其他文件資訊。

**交付界線:** 發布、停用下載與補清理是同一個可驗收切片，不能只交付刪檔或只交付畫面。

## 04: 大量更新、相容與整合交付驗證

**What to build:** 以完整使用者流程驗證既有文件、大量簽署與故障恢復都可使用新機制，提供同版切換與修正版回復說明，使整合結果可交付。

**Blocked by:** 03：新版成功後取代與清除舊 ZIP

**對應 Tasks:** T029–T032

**Status:** 草案，待使用者確認（發布後 ready-for-agent）

- [ ] 既有多版及缺檔資料相容；升級不自動全量打包、刪檔或改寫歷史。
- [ ] 6,000 份具代表性 PDF 能完成背景更新，記錄實際耗時、記憶體與完整性，不以複製小檔替代。
- [ ] 瀏覽器完整驗收最新、過時、處理中、失敗、取代及雙 session 舊頁操作。
- [ ] 對應 server unit/e2e/storage、前端 lint、跨 package build/lint 完成；未執行項目及原因明列，不宣稱通過。
- [ ] 部署說明包含 client/API/worker 同版切換、舊 worker 停止、不可直接回退不識別新狀態的舊程式，以及已刪 ZIP 不可復原。
- [ ] 不包含實際部署、遠端 PR 或正式資料操作；驗收通過並整合至功能整合分支後才可 resolved。

## 依賴與領取

01 → 02 → 03 → 04。每張都是可示範或可獨立驗證的切片；共用匯出流程與檔案，順序整合比平行改動同一流程更安全。票內獨立測試準備可依 tasks 的 [P] 並行。
